# Student Task Manager

A simple web-based **Student Task Manager** developed as a pair-based collaborative project using Git and GitHub.

The application allows users to add tasks, display tasks,  delete tasks, and search for tasks. The main purpose of this project is to demonstrate a real collaborative software-development workflow using Git and GitHub.
